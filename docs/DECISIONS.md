- 2026-10-22 - Correct the simplified reopening spec to track cumulative short all-ins per player - Poker TDA's no-limit rule reopens a player facing a full-raise increment since their latest action, even if separate short all-ins supplied it. Retain the last full raise size; callers who acted at a later wager may still be locked. Source: https://www.pokertda.com/view-poker-tda-rules/
- 2026-10-22 - Track committed as hand-total contributions including current bets - Keep one source of truth for chips; totalChips sums stacks plus committed, and street transitions clear bet without discarding contributions. A later settlement layer will return uncalled excess and award pots.
- 2026-10-22 - Retain nominal BB sizing with multiple actors after a short blind; forbid wagers no opponent can call - When only one active player remains, only actual live bets require matching. Cap blind posts at stacks and let settlement handle uncalled overage.
- 2026-10-22 - Stage mid-hand departure behavior safely - New arrivals can wait for the next hand, but removePlayer rejects any unsettled round until fold/deferred-removal and settlement are implemented. This prevents committed chips disappearing in the meantime.
- 2026-10-22 - Correct uncalled-return eligibility in the pot spec - Only a layer with one contributor is uncalled. Multiple contributors with one remaining eligible winner create a real pot award, including folded money. Slice all contribution levels and merge adjacent equal-eligibility pots.
- 2026-10-22 - Orchestrate complete hands above the low-level betting helpers - Root applyAction advances/deals/settles whenever a round closes; existing isolated betting tests continue to work on states without a hand. Fold wins never run out or reveal private cards.
- 2026-10-22 - Retain hand identity and participant IDs with hole cards - Authorize views and private deal events against seat, player ID and hand ID to prevent leaking old cards when seats are reused. Raw engine state/events remain internal; M3 must build views and filter events separately per recipient.
- 2026-10-22 - Inject timestamps into full-hand commands - Deterministic test clocks default to zero or the prior injected time; server code must pass its clock. Engine commands never read Date.now or own timers.
- 2026-10-22 - Queue mid-hand departure folds until the player's next legal turn; retain all-in eligibility - Replaces the original out-of-turn fold-now rule. Immediate removal/folding of an all-in or a nonacting side-pot participant could discard chips or strand a pot with no eligible player. Remove participants only after payout and report the exact stack withdrawal; waiting newcomers can leave immediately. Preserve another actor's existing deadline.
- 2026-10-22 - Consecutive timeouts trigger sit-out at settlement - Automatic actions preserve/increment the count; a manual poker action resets it. Explicit sit-in clears both timeout count and the voluntary next-hand sit-out flag; a manual sit-out does not fold a current hand.
